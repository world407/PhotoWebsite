# 摄影产品 UX 规格

> Phase 0 视觉逆向分析产出 | 摄影网站产品化规划

---

## 1. 产品定位

**影·迹 PHOTOGRAPHY** 是一个面向摄影师的视觉叙事平台，核心价值是「展示」与「发现」。

- **目标用户**：摄影师（创作者）+ 摄影爱好者（浏览者）
- **核心体验**：沉浸式照片浏览、低干扰的视觉消费
- **设计调性**：暗调、电影感、高端画廊品质
- **差异化**：金色高光 + 深色背景的独特品牌记忆点，区别于主流白色摄影平台

### 2.1 已具备的核心体验

## 3. 页面扩展规划（不破坏视觉语言的前提下）

### 3.1 Gallery（画廊/探索页）— 扩展现有 Works 区

**当前状态**：首页一个区块，CSS columns 瀑布流，9 张作品，前端筛选。

**扩展方向**：

1. **独立路由**：`/explore` 或 `/gallery`
2. **筛选增强**：
   - 分类标签保留现有 chip 设计
   - 新增排序：最新 / 最热 / 推荐
   - 新增筛选：颜色、设备、时间范围（使用下拉/弹出层，保持 chip 视觉语言）
3. **瀑布流增强**：
   - 考虑迁移至 CSS Grid + `grid-template-rows: masonry`（渐进增强）或虚拟滚动（大量图片时）
   - 图片比例保持 3:4 / 4:5 / 1:1 / 16:9 等摄影常见比例
4. **分页/加载更多**：
   - 不使用传统分页器（破坏浏览流畅性）
   - 使用「加载更多」按钮或无限滚动（IntersectionObserver 触发）
   - 加载更多按钮复用 btn-outline 样式
5. **卡片信息密度**：
   - 默认保持现有简洁（hover 显示标题/作者/点赞）
   - 可切换视图：紧凑（仅图片）/ 标准（现有）/ 详细（增加描述标签）

### 3.2 Photo Detail（照片详情页）— 全新页面

**核心原则**：全屏沉浸式，图片最大化为第一优先级。

**推荐布局**：

```
┌─────────────────────────────────────────┐
│  ← 返回    ♡ 点赞    ⤴ 分享    ⋯ 更多  │  ← 透明浮动工具栏
├─────────────────────────────────────────┤
│                                         │
│            （全屏大图展示）              │  ← 黑色背景，图片居中
│            object-fit: contain          │
│            max-height: 90vh             │
│                                         │
├─────────────────────────────────────────┤
│  标题                   ♡ 1,248         │
│  @林风 · 2026年3月 · 风光               │
│  描述文字...                            │
│  标签: #山景 #晨雾 #自然光               │
│  ─────────────────────────────────────  │
│  EXIF: Sony A7IV · 24-70mm f/2.8        │
│        1/250s · f/8 · ISO 100           │
├─────────────────────────────────────────┤
│  评论区 / 相关作品推荐                   │
└─────────────────────────────────────────┘
```

**视觉语言延续**：
- 背景：比主页更深 `#060609` 或纯黑，突出图片
- 工具栏：半透明玻璃态，滚动态类似导航的 pill 浮起
- 文字：沿用 text-body / text-caption 层级
- 金色点缀：仅用于活跃状态（已点赞/关注）
- 动效：
  - 图片淡入（opacity 300ms）
  - 工具栏滚动时 morph（类似导航）
  - 左右箭头切换图片（键盘 ← → 支持）
  - Lightbox 模式：点击图片进入全屏纯图模式

**交互细节**：
- 点击/按 Esc 返回画廊（保持滚动位置）
- 左右键/滑动切换上一张/下一张
- 双击图片放大（2x zoom）
- 右键保护（可选，摄影师需求）
- 图片水印（可选，摄影师可设置）

### 3.3 Projects（专题/项目集）— 全新页面

**设计逻辑**：摄影师常以「项目」为单位创作（如「东京街头」「冰岛极光」）。

**卡片设计**：
- 与 WorkCard 区分：更大尺寸、标题常驻（非 hover 显示）、包含项目描述
- 布局：大卡片 masonry 或全宽横幅交替
- 封面：使用项目代表作品，比例 16:9 或 3:2
- hover：项目名 + 作品数量从底部淡入

**列表页**：
- 顶部精选项目大横幅（Hero 级展示）
- 下方项目网格
- 筛选：所有项目 / 我关注的 / 热门

**项目详情页**：
- 类似 Photo Detail 但支持多图叙事流
- 图片间穿插文字（摄影师自述）
- 横向滚动或纵向流式

### 3.4 About（关于页）— 全新页面

**设计方向**：品牌故事页，保持暗调美学。

**内容板块**：
1. Hero：大图 + 品牌宣言（沿用 Hero 左文右图布局，比例调整为 50/50）
2. 平台数据：沿用 Stats Grid 但更大展示
3. 团队/理念：文字 + 图片交错布局
4. 常见问题：折叠面板（accordion）
5. CTA 区：加入/上传引导

**视觉延续**：
- 使用 section padding 规范（py-20/24）
- 分割线使用 border-subtle
- 标题沿用 text-h2 规范

### 3.5 Journal（日志/博客）— 全新页面

**设计逻辑**：摄影教程、器材评测、摄影师访谈等图文内容。

**卡片设计**：
- 与图片卡片区分：增加标题/摘要/日期/作者
- 比例：4:3 封面图 + 下方文字区
- 布局：标准 grid（非瀑布流），更规整
- hover：translateY(-4px) + 阴影（沿用 card-hover）

**文章页**：
- 阅读宽度：max-w-2xl（720px）居中，保证长文可读性
- 正文：text-body leading-relaxed，段落间距 space-y-6
- 配图：全宽图片，rounded-img，插入正文中

### 3.6 Contact（联系页）— 全新页面

**简洁设计**：
- 左侧：联系信息（邮箱/合作/社交媒体）
- 右侧：表单（姓名/邮箱/主题/消息/提交按钮）
- 表单样式：
  - 输入框：bg-bg-card border border-subtle rounded-btn px-4 py-3
  - focus：border-accent + 金色发光 outline
  - 按钮：btn-accent（提交）
- 背景：可加入大尺寸半透明摄影图作为装饰

### 3.7 Admin/Upload（管理后台/上传页）— 功能页面

**设计原则**：功能优先，但保持视觉系统一致。

**上传页**：
- 拖拽区域：dashed border-accent rounded-card，大尺寸
- 上传后编辑：标题/描述/标签/EXIF/封面选择
- 图片预览：上传后即时显示缩略图网格
- 发布按钮：btn-accent（固定底部或右上角）

**管理面板**：
- 左侧边栏：深色 bg-bg-deep，导航项
- 右侧内容区：bg-bg-base
- 数据表格：使用 bg-bg-card 行分隔，hover 行高亮
- 保持设计系统的按钮/标签/间距规范

## 4. 导航扩展规划

### 4.1 桌面导航扩展

当前 4 项 → 建议扩展为 6 项：

```
首页 | 探索 | 专题 | 摄影师 | 日志 | 关于
```

- 超过 6 项时考虑：将次级项收入下拉菜单或「更多」
- 保持 gap-8 间距
- 上传按钮和搜索/头像保持在右侧

### 4.2 移动端抽屉扩展

当前 7 项（含上传按钮）→ 保持类似结构，增加「专题」「日志」入口。

### 4.3 路由与导航状态

- 每个顶级页面对应导航 active 状态（金色 + 下划线）
- 使用前端路由（React Router / Next.js App Router 等）
- 页面切换时：考虑淡入过渡或保持无过渡（摄影站不宜过动）

## 5. 摄影特有 UX 模式

### 5.1 图片浏览交互

| 交互 | 规范 |
|---|---|
| 鼠标悬停预览 | 已有 overlay 显示信息 |
| 点击打开大图 | Photo Detail 页或 Lightbox |
| 双击放大 | 2x zoom，移动端双指缩放 |
| 键盘导航 | ← → 切换，Esc 退出 |
| 滑动导航 | 移动端左右滑动切换图片 |
| 长按保存 | 移动端可触发（可由摄影师设置禁止） |

### 5.2 图片加载体验

1. **渐进式加载**：先加载低质量占位图（LQIP），渐入高清图
2. **颜色占位**：可提取图片主色调作为 placeholder 背景（替代 shimmer 的高级方案）
3. **加载失败态**：显示重试按钮 + 灰色占位图
4. **首屏优先级**：Hero 图片 fetchpriority="high"，预连接 Unsplash CDN

### 5.3 社交互动

| 功能 | 交互设计 |
|---|---|
| 点赞 | 心形图标，点击时 scale(1.2) 弹跳 + 变金填充 |
| 收藏 | 书签图标，同点赞 |
| 关注 | 已有 btn-follow 设计 |
| 分享 | 分享面板弹出（底部抽屉，复用 mobile-drawer 样式） |
| 评论 | 展开评论区，输入框 bg-bg-card border-subtle |

### 5.4 搜索体验

1. 点击搜索图标 → 展开搜索框（导航 morphs）
2. 输入时即时搜索建议（标签/摄影师/作品名）
3. 搜索结果页：三列切换（作品/摄影师/专题）
4. 热门搜索标签（复用 tag-chip 样式）

## 6. 视觉语言扩展指南

### 6.1 新增页面必须遵守

1. **背景色**：统一使用 `--color-bg-base` 或 `--color-bg-deep`，不引入新背景色
2. **强调色**：只有金色 `--color-accent`，不引入其他彩色
3. **文字三级**：primary / secondary / muted，严格按层级使用
4. **圆角规范**：卡片 16px / 按钮 12px / 图片 8px / 胶囊 999px
5. **间距基准**：4px 为基数，使用 8/12/16/20/24/32/48px 序列
6. **卡片 hover**：统一 translateY(-4px)，不使用其他方向/距离
7. **过渡时长**：hover 0.2-0.25s / 结构变化 0.3-0.4s / 入场 0.6s
8. **缓动函数**：统一 `cubic-bezier(0.4, 0, 0.2, 1)` 为主

### 6.2 新组件设计方向

| 新组件 | 参考现有 | 注意事项 |
|---|---|---|
| 输入框 | — | bg-card border-subtle rounded-btn, focus:border-accent |
| 下拉菜单 | TagChip 扩展 | bg-card 背景，rounded-card 圆角，py-2 |
| 模态框 | MobileDrawer 变体 | 居中弹出，bg-card 背景，shadow-modal，rounded-card |
| 提示 Toast | — | 底部居中，bg-card 背景，rounded-card，自动消失 |
| 分页器 | — | 圆形页码按钮，当前页 bg-accent |
| 折叠面板 | — | border-subtle 分隔，展开/收起旋转箭头 |
| Tabs | TagChip 扩展 | 类似标签但更大，下划线指示 active |
| 徽章 Badge | Logo 金点扩展 | 小圆形或圆角矩形，bg-accent 或 bg-card |

### 6.3 禁止事项

- 禁止引入金色系以外的彩色（如蓝/紫/绿/红）作为品牌色或强调色
- 禁止使用大于 16px 的圆角（保持专业感，不变成 iOS 风）
- 禁止使用弹跳/弹性（spring/bounce）缓动
- 禁止使用投影过重的 neumorphism / 新拟态效果
- 禁止在图片上添加彩色滤镜/色调（保持照片原始色彩）
- 禁止文字使用纯白以外的颜色作为 primary 文字

## 7. 数据模型建议（UX 视角）

从 UX 反推需要的数据字段：

```
Photo（作品）
├── id
├── title
├── description
├── imageUrl (multiple sizes: thumb/medium/large/original)
├── aspectRatio
├── dominantColor (for placeholder)
├── tags[]
├── exif { camera, lens, aperture, shutter, iso, focalLength, date }
├── author -> Photographer
├── likes
├── views
├── comments[]
├── project -> Project?
├── uploadedAt
└── settings { allowDownload, watermark }

Photographer（摄影师）
├── id
├── name
├── username (@handle)
├── avatar
├── bio
├── coverImage
├── location
├── worksCount
├── followersCount
├── followingCount
├── isFollowed
├── works[] -> Photo
└── projects[] -> Project

Project（专题）
├── id
├── title
├── description
├── coverImage
├── photos[] -> Photo
├── author -> Photographer
├── createdAt
└── views

JournalPost（日志）
├── id
├── title
├── excerpt
├── coverImage
├── content (markdown/HTML)
├── author
├── tags[]
└── publishedAt
```
